Heuristic swing-pivot pattern detection, not a certified charting engine or investment advice — I'm not a licensed advisor. "Retest" checks whether price revisited the breakout level within a timeframe-scaled window; "support held" checks it didn't close back through that level in the following few sessions. "Successful/Failed" outcome is based on the 30-trading-day forward return relative to breakout direction, so very recent breakouts show "In Progress" until that window completes. Historical evidence stats aggregate every instance found across your loaded universe and history depth — small n means a rougher estimate, shown next to each stat. Data is a static snapshot from your last script run; see the script for scheduling it to refresh automatically each day.
